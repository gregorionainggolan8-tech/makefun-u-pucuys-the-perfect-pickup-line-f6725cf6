A tiny deterministic Node program that writes one short pickup line an AI agent could actually say out loud.

## The line

> I ran a million simulations of this exact moment, and in every single one, you smiled — so I figured I'd better come say hi.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

No network, no model calls — the line is a literal string in `main.ts`, so every run writes byte-identical output.
